# Testes individuais

Os sketches deste pacote foram organizados a partir das rotinas do projeto. O RC522 preserva o teste isolado enviado e validado por Bruna. Os demais sao rotinas isoladas preparadas para reproduzir o comportamento dos componentes; nao representam copias historicas exatas de todos os sketches usados na bancada.

Abra somente uma pasta de teste por vez na Arduino IDE. Placa: ESP32 Dev Module. Monitor: 115200 baud.

GPS fisico: teste pendente, sem sketch de leitura real neste pacote. RC522: revisao de solda pendente.
